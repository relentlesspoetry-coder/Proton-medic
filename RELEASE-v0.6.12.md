# Proton Medic v0.6.12

## Interface

- Redesign the workspace with dark navy surfaces, restrained blue accents, consistent typography, and simpler spacing.
- Replace the floating sidebar with a slimmer navigation rail while retaining the original logo.
- Reorganize Home around a library overview, a compact status strip, and three clear actions.
- Use flatter game lists with compact status labels and fewer repeated descriptions. Full findings remain in each game's details.
- Simplify Windows game controls and style the installer and existing-game choices as a single tab group.
- Unify forms, notices, buttons, diagnostics, and advanced sections across the application.
- Adapt layouts to desktop, Steam Deck-sized displays, and narrow windows. Retain visible keyboard focus, reduced-motion settings, and high-contrast support.
- Add rendered layout and accessibility checks before native release validation.

Game discovery, installation, launch tests, extracted icons, renaming, removal and restoration, shortcuts, repairs, backups, and signed automatic updates remain available.

## Update

Choose **Check for updates** at the top right, review the release, and approve installation. From v0.6.11 onward, Proton Medic automatically opens the installed version after updating.

Requirements: Ubuntu 24.04-compatible amd64 Linux, glibc 2.39 or newer, GTK 3, and WebKitGTK 4.1.
