# Proton Medic v0.6.18

- My Games now combines Steam games and visible Windows game profiles in one searchable library.
- Added Steam/Windows source filters, locally saved favorites, and recently played sorting. Different installations and sources keep separate identities, even when their names match.
- Recent sorting uses available Steam manifest timestamps and recorded Windows game launches, including desktop shortcuts. Unknown dates appear last; installer runs and failed runtime starts do not replace a previous Windows game launch date.
- Selecting a Windows game opens its existing controls, launch settings, history, resource monitor, and shortcuts. Returning to My Games preserves the search and filters.
- Windows Games remains available for installing, adding, and restoring games. Removed profiles stay out of the combined list.
- Temporary Windows library failures retain previously loaded games and provide a retry action.

Use **My Games**, select a source or filter, and use the star beside a game to save a favorite. Signed DEB and AppImage updates remain available.
