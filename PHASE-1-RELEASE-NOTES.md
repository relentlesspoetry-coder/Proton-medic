# Proton Medic v0.1.0 — Steam discovery

Source preview.

## Added

- Tauri 2 desktop application with a React and TypeScript interface.
- Read-only discovery of native and Flatpak Steam installations.
- Multiple Steam libraries, game manifests, install paths, and Proton prefix paths.
- Listings of installed compatibility tools.
- Game search, filters, overview statistics, details, warnings, and rescan controls.
- Five Rust scanner tests using temporary Steam fixtures.

This version covers library discovery. Log analysis, system diagnostics, and repairs were added in later releases.

## Checks

JSON parsing and source contract checks passed. Native compilation and desktop launch were not tested for this version.
